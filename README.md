# E-ticaret sipariş API'si

Omerd için sipariş kayıtlarını tutan HTTP API.

## Ne var

Sipariş uçları `OrdersController` içindedir. Swagger geliştirme adresinde açılır.

## Çalıştırma

```powershell
dotnet run --project ECommerceOrderManagement
```

## Yığın

.NET 9, Entity Framework Core, bellek içi veritabanı, OpenAPI.
